Core Pillars

The Sovereign Evolution (v8.3.0)

VIKI balances the raw power of LLMs with the safety of a modular, capability-aware architecture.

🧠 Intelligence Governance

Every directive is filtered through cognitive triage (Reflex, Shallow, Deep) to ensure the right model is used for the right task while maintaining absolute safety.

⚒️ The Neural Forge

Extracts wisdom from semantic memory and bakes it into local Ollama images (default tag viki-neural-forge) on top of base models like Phi-3, Mistral, Qwen, or DeepSeek.

🔒 Capability-Aware Execution

Granular permission gating via centralized CapabilityRegistry ensures high-risk actions like filesystem_write and shell_exec never bypass security protocols.

🔄 Recursive Self-Reflection

The Reflection Layer critiques plans before execution, reducing hallucinations and improving tool-use accuracy across complex multi-step tasks.

🏗️ Clean Architecture

Decoupled, testable system powered by Dependency Injection following Hexagonal Architecture and Domain-Driven Design principles for enterprise-grade expansion.

⚡ Rapid Reflex Pipeline

Dedicated short-circuit path for sub-second responses. Common intents bypass the full deliberation stack for near-instant execution.

Quick Start

Get running in minutes

VIKI runs on Python 3.10+ with Ollama. Install, configure, and launch.

1

Clone the repository

Clone VIKI from GitHub to your local machine.

git clone https://github.com/Orythix/viki.git && cd viki
2

Install dependencies

Create a virtual environment and install the package with development tools.

python -m venv .venv && source .venv/bin/activate && pip install -e ".[dev]"
3

Configure environment

Copy the example config and set your Ollama endpoint and preferred model.

cp .env.example .env && # edit .env with your settings
4

Launch VIKI

Start the CLI and interact with your sovereign digital intelligence.

python -m viki
